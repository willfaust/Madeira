# WoW64 binaries (optional, stacked on the D3D9 series)

Built artifacts for the 32-bit series, for testing it before the farms can be
rebuilt on macOS. Every file is copied unchanged from the 125hz fork's committed
farms at `integration/upstream-0926` (8e45bef). They were produced by the fork's
WSL build rounds (`.xtool` stage scripts, the logic that `build/wine-i386/build.sh`
and `build/dxmt-ios/build.sh` express for macOS) from the fork's branches:
wine `integration/upstream-0926` (be9ed8b), FEX `wip/ml2000` (7b528d8) and
dxmt `wip/ml2000` (6a1c8c5). Those branches are the sources of this series and
its companion changes **plus** the fork's other work (Steam, media, controller
extras), so these files are not a rebuild of exactly the reviewed sources. The
last column names the fork commit that last changed each file; several were
built in earlier rounds of the same branches.

Not included: `dockhost.exe` and its notices, the D3D12 runtime
(`d3d12.dll`/`madeira_d3d12.dll` and the `dcomp`/`ktmw32` stubs of the 64-bit
farms), the media modules (`winegstreamer.dll`), and the fork's other 32-bit
test programs. The 64-bit files are the ones the WoW64 and D3D9 changes touch:
the aarch64 WoW64 layer (`wow64`, `wow64win`, `xtajit`), `ntdll`, `nsi`, and
DXMT's `winemetal`/`d3d11`/`dxgi`/`d3d10core`/`d3d9`.
